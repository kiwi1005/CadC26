## 12.4 Risk register

| 風險 | 影響 | 預警 | 緩解 |
|---|---|---|---|
| 官方不提供 GPU | full profile不可用 | 規格未明示 | portable profile、詢問主辦方 |
| spec drift | scorer不一致 | README/evaluator更新 | pin commit/hash、CI parity |
| validation overfit | hidden退化 | 100 val反覆調參 | internal dev/test、限縮 val使用 |
| initializer mode collapse | K無收益 | descriptor相似 | best-of-K、DPP/novelty loss |
| rollout drift | dynamics爆炸 | energy/velocity上升 | noise training、damping、step cap |
| BDP direction錯誤 | infeasible/大位移 | primal residual高 | direction beam、flip low confidence |
| cluster latch死鎖 | topology卡住 | latch反覆或無改善 | hysteresis、contact rewire event |
| MIB不可相容 | soft violation | area interval空 | hard area優先、soft slack |
| FP precision | near-touch overlap | exact verifier偶發 fail | FP32、margin、CPU double |
| runtime tail | leaderboard被懲罰 | p95/p99上升 | hard budget、anytime incumbent |
| data I/O bottleneck | GPU低利用 | dataloader idle | tar shards、NVMe、prefetch |
| model load/compile | cold start過長 | first case outlier | eager warmup、cache、small portable |

## 12.5 Freeze 規則

submission 前 48 小時：

- 不改 geometry semantics；
- 不改 checkpoint architecture；
- 不改 evaluator adapter；
- 只允許 packaging/paths/timeout fix；
- 每次改動都跑 quick + 100-case dry run；
- 保存最後三個已知可提交 artifact。
