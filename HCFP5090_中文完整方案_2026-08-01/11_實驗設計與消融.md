# 11　實驗設計與消融

## 11.1 主指標

官方：

- v10 weighted total score；
- per-case cost；
- hard feasibility；
- HPWL gap、area gap、V_rel；
- runtime（正式 leaderboard 才有真實 factor）。

工程診斷：

- overlap pair/count/area/max depth；
- cluster components；
- boundary/MIB violations；
- projection displacement；
- BDP success/iterations/primal residual；
- event trigger/type/success；
- oracle@K、PVR regret；
- population diversity；
- p50/p95/p99 runtime。

## 11.2 必要 baselines

全部從零或公開實作，不能拿舊專案當核心：

1. deterministic shelf fallback；
2. random population + BDP；
3. analytic collective dynamics + BDP；
4. POP-INIT + analytic dynamics + BDP；
5. POP-INIT + learned block dynamics + BDP；
6. full HiCoDy + CAL + ETR + BDP；
7. optional literature baselines：B*-tree SA、analytical optimizer、公開 RL/generative method（若能公平移植）。

## 11.3 核心 ablation matrix

| Ablation | 要回答的問題 |
|---|---|
| remove learned initializer | 1M data 是否真的改善起點 |
| K=1 vs 8/32/64/96 | population 的邊際收益 |
| remove region level | 多尺度是否必要 |
| remove global density field | pairwise 是否足夠 |
| analytic-only vs learned residual | learning interaction 的淨貢獻 |
| no CAL / no hysteresis | latch 是否降低 cluster 震盪 |
| random shake vs ETR | 事件式重配置是否優於盲擾動 |
| min-displacement dir vs learned dir | direction learner 的價值 |
| beam 1/4/8/16 | BDP topology coverage/runtime tradeoff |
| no projection-outcome training | repair-aware training 是否重要 |
| BF16 vs optional FP8 | 效能與 QoR/數值風險 |

## 11.4 Evaluation protocol

- 至少 5 model/inference seeds；
- internal test 與 official validation 分開；
- 報 mean、median、bootstrap 95% CI；
- paired per-case comparison；
- 大案例 106–120 單列；
- 任一新增 cost=10 case 視為重大 regression；
- 不只報 oracle@K，必須報實際 PVR top-1/BDP output。

## 11.5 Acceptance gates

### P0 correctness

- official parity unit tests 100%；
- fallback hard feasibility 100%；
- fixed/preplaced exact replay 100%；
- deterministic repeatability。

### P1 dynamics

- analytic dynamics 相對 random init 顯著降低 overlap與 projection movement；
- 120-block K=32 無 NaN/OOM；
- p95 runtime受控。

### P2 model

- learned initializer oracle@K 超過 analytic/random；
- learned dynamics 的 post-BDP score改善，不只 raw surrogate改善；
- large-case不退步。

### P3 default promotion

- 100 validation hard feasibility 100%；
- v10 weighted score至少有實質改善且跨 seeds穩定；
- p95 runtime在預定 cap內；
- portable fallback通過封裝。

## 11.6 Generalization tests

- N 留一區間，例如 train弱化 111–120，測 large extrapolation；
- constraint density extreme；
- pin distribution shift；
- area/aspect outliers；
- preplaced obstacle maze；
- cluster/MIB overlap；
- random block permutation；
- D4 transform consistency。
